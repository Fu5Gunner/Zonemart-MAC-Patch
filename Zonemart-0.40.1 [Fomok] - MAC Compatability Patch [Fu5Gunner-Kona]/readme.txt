ZONEMART 0.40.1 by [Fomok] - MOD APP CREATOR (MAC) PATCH - by [Fu5Gunner-Kona]

Adds Zonemart as an app on the MAC PDA launcher. Install as a SEPARATE MO2 mod,
placed BELOW (higher priority than) both Zonemart and Mod App Creator, because it
overwrites Zonemart's modxml_fmk_market_pda.script.


Behaviour:
- MAC installed: Zonemart's PDA tab gets folded into the MAC tab and
  Zonemart will now appear inside the MAC/Launcher tab with its own icon.

-If MAC is not detected or is not installed correctly. Zonemart will default to its normal state of a scrollable tab inside PDA
-
- I did not touch trader/offline dialog

IMPORTANT: requires Modded Exes 2025.8.23+ (a MAC requirement). If the tab buttons
disappear after opening Zonemart from the launcher, use MAC's "Return to Launcher" key (default Right Ctrl).
